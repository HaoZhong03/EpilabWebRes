# AGENTS.md — EpiLab Website

## What this repo is

A Hugo static site for the EpiLab research group (China Agricultural University), built on the **HugoBlox** (formerly Wowchemy) `starter-hugo-research-group` theme.

- **Framework**: Hugo (Extended) + Go modules
- **Theme**: HugoBlox Bootstrap v5 (`blox-bootstrap/v5`)
- **Default language**: Chinese (`zh`), single-language site
- **Content directory**: flat `content/` (not `content/zh/`)

## Development commands

| Task | Command |
|------|---------|
| Local preview (incl. drafts) | `hugo server -D` |
| Build static output | `hugo` |
| Output directory | `public/` |

There is **no package.json, no CI pipeline, and no test suite**. The only build tool is Hugo. There is also **no linter, no formatter, and no pre-commit hooks** — the only style rules are in `.editorconfig`.

## Architecture & customizations

### Config location
All Hugo config lives in `config/_default/`:
- `hugo.yaml` — site metadata, URLs, taxonomies
- `languages.yaml` — single `zh` locale
- `menus.yaml` — top nav (首页 / 新闻 / 团队 / 项目 / 成果 / 联系我们)
- `module.yaml` — Hugo module imports (blox-bootstrap, decap-cms, netlify)
- `params.yaml` — theme params, SEO, features

### Important config quirks
- `uglyURLs: true` → pages render as `.html` files, **not** pretty `/slug/` directories.
- `relativeURLs: true` → links are relative, not absolute.
- `defaultContentLanguage: zh` with `hasCJKLanguage: false`.

### Custom layouts (override theme defaults)
- `layouts/partials/blocks/v1/about.html` — **heavily customized** author/about block. It reads `assets/data/article.csv` and renders a "近期发表" (recent publications) list per author by matching Chinese or English names.
- `layouts/partials/custom_js.html` — runtime JS patch that rewrites carousel background images from absolute `/media/` paths to relative `./media/` paths.
- `layouts/shortcodes/article_table.html` — renders a sortable/searchable HTML table from `assets/data/article.csv`.
- `layouts/shortcodes/card.html` — simple linked card with optional image.
- `layouts/shortcodes/toc.html` — generates a fixed left-side TOC from headings in `.article-style`.

### Custom styles
- `assets/scss/template.scss` — overrides for carousel arrows (hidden), profile zoom (`0.8`), email-as-text-button styling, and font-size reductions across article content.

### Data dependency
- `assets/data/article.csv` is **required** by the custom about block and `article_table` shortcode. If missing, the about block emits a warning and the shortcode shows an error.

## Content structure

```
content/
  _index.md              # Landing page with slider + news collection + CTAs
  authors/               # 17 author profiles (e.g. HaoZhong/_index.md)
  contact/
  news/
  people/
  projects/
  publication/
```

Author profiles use Wowchemy front-matter: `title`, `first_name`, `last_name`, `role`, `organizations`, `bio`, `interests`, `education.courses`, `social`, `user_groups`.

### Media
- Images referenced in content (e.g. slider backgrounds) should go in `assets/media/` or `static/media/`.
- The custom JS in `custom_js.html` expects carousel images to be resolvable at `./media/<filename>`.

## i18n
- `i18n/zh.yaml` — minimal overrides: `interests` → "研究方向", `introduce` → "个人简介".
- Theme-provided translations are merged automatically.

## Go module note

`go.mod` declares `go 1.15` and pins HugoBlox modules. If you need to update theme versions, run `hugo mod get -u` (requires Go installed). You can also run `hugo mod tidy` or `hugo mod vendor` when theme deps change.

## Editor & generated-file conventions

- `.editorconfig` enforces: 2-space indent, LF, UTF-8, final newline. **Do not trim trailing whitespace in `*.md`**.
- `assets/jsconfig.json` is auto-generated by Hugo and contains machine-local absolute paths. Do not hand-edit it; if a fresh clone regenerates it, that is expected.
- `resources/_gen/` and `public/` are build artifacts and are gitignored.

## Editing guidance

- **Front page edits**: `content/_index.md` uses `type: landing` with `sections` blocks (`slider`, `markdown`, `collection`).
- **Adding a team member**: create `content/authors/<Name>/_index.md` and optional `avatar.jpg`.
- **Adding a publication**: update `assets/data/article.csv` (used by custom about block and article_table shortcode). The CSV columns are: title, authors, date, doi, type, journal — inspect `layouts/partials/blocks/v1/about.html` and `layouts/shortcodes/article_table.html` for how each column is consumed.
- **Nav links**: edit `config/_default/menus.yaml`, and use `.html` suffixes because `uglyURLs: true`.
